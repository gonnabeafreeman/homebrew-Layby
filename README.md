# Gonnabeafreeman Layby

## How do I install these formulae?

`brew install gonnabeafreeman/layby/<formula>`

Or `brew tap gonnabeafreeman/layby` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gonnabeafreeman/layby"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
